# ✊✋✌ Rock Paper Scissors Game

A fun and interactive Rock Paper Scissors game built using **HTML, CSS, and JavaScript**. Play against the computer and test your luck!

## 🚀 Features

- 🎮 Simple and easy-to-use interface
- 🖥️ Player vs Computer gameplay
- 📊 Live score tracking
- 🔄 Reset button to restart the game
- 🎨 Responsive design

## 📥 Installation & Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/AshishSinsinwal/RockPaperScissor.git
   ```
2. Navigate to the project folder:
   ```bash
   cd RockPaperScissor
   ```
3. Open `index.html` in your browser.
